# cakebar

CakeBar — shirinliklar onlayn-do'koni (Django). Mahsulotlar, savat, buyurtma, pulni qaytarish (refund), wallet, sevimlilar, admin panel va UZ/RU/EN til qo'llab-quvvatlash.

## Ishga tushirish

```bash
python manage.py migrate
python manage.py seed
python manage.py seed_pages
python manage.py createsuperuser
python manage.py runserver
```
